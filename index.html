FAQ常见问题

Frequently Asked Questions常见问题解答

01 What is VibeFlow Studio?VibeFlow Studio 是什么？
VibeFlow Studio is an AI-native CAE workbench. It connects natural-language instructions with geometry, meshing, solver-backend input generation, computation, post-processing, Markdown/LaTeX writing, and evidence-traced reports. It provides Usage Mode for complete simulation workflows and Development Mode for custom solver-side capabilities. VibeFlow Studio 是一个 AI 原生 CAE 工作台。它把自然语言指令与几何、网格、求解器后端输入生成、计算、后处理、Markdown/LaTeX 写作和证据追溯报告连接起来。它提供面向完整仿真流程的使用模式，以及面向自定义求解能力的开发模式。
02 Which CAE software can VibeFlow assist?VibeFlow 可以辅助哪些 CAE 软件？
VibeFlow is designed around mainstream open-source CAE backends, including OpenFOAM, CalculiX, Code_Aster, Elmer, FDS, FEniCS, FreeFEM, LAMMPS, MOOSE, Nektar++, OpenLB, OpenRadioss, SU2, DualSPHysics, PETSc, SPHinXsys, and related tools such as CadQuery, Gmsh, ParaView, FreeCAD, and LaTeX. VibeFlow 面向主流开源 CAE 后端设计，包括 OpenFOAM、CalculiX、Code_Aster、Elmer、FDS、FEniCS、FreeFEM、LAMMPS、MOOSE、Nektar++、OpenLB、OpenRadioss、SU2、DualSPHysics、PETSc、SPHinXsys，以及 CadQuery、Gmsh、ParaView、FreeCAD、LaTeX 等配套工具。
03 Do I need to be a CAE software expert?使用 VibeFlow 需要精通 CAE 软件吗？
No. VibeFlow is built for users who understand their engineering problem but may not remember every solver keyword, dictionary syntax, mesh setting, or post-processing command. Visual parameter forms, built-in skills, local references, Add to Chat, and screenshot prompts help translate intent into accurate instructions. Domain judgment is still important for choosing assumptions and interpreting results. 不需要。VibeFlow 面向“懂工程问题，但不一定记得每个求解器关键字、字典语法、网格设置或后处理命令”的用户。可视化参数表单、内置 skills、本地知识库、Add to Chat 和截图 prompt 会把意图转化为准确指令。但物理假设选择和结果解读仍需要工程判断。
04 What is caseDict and why is it the single source of truth?caseDict 是什么，为什么是单一事实源？
0-caseDict/caseDict is the structured definition of the simulation case: intent, physical problem, geometry parameters, materials, regions, interfaces, boundaries, loads, initial values, mesh targets, numerical method, execution settings, post-processing objectives, artifacts, errors, and workflow state. Downstream geometry, mesh, solver inputs, results, and reports must trace back to it. 0-caseDict/caseDict 是仿真算例的结构化定义：意图、物理问题、几何参数、材料、区域、界面、边界、载荷、初值、网格目标、数值方法、运行设置、后处理目标、产物、错误和工作流状态。下游几何、网格、求解器输入、结果和报告都必须可追溯到它。
05 How do Add to Chat, screenshots, and visual forms help?Add to Chat、截图和可视化表单有什么用？
They make prompts precise. Selected code or log fragments can be inserted into the chat directly; screenshots can be saved and added to prompt context; OpenFOAM parameter pages explain mathematical meaning and recommended choices. This reduces vague instructions and helps the Agent perform exact geometry, mesh, solver, and report adjustments. 它们让 prompt 更精确。选中的代码或日志片段可以直接加入对话；截图可以保存并加入 prompt 上下文；OpenFOAM 参数页面会解释数理含义和推荐选择。这减少了模糊指令，帮助 Agent 精确调整几何、网格、求解器设置和报告内容。
06 Are my simulation files stored in the cloud?我的仿真文件会上传到云端吗？
Project artifacts — geometry, mesh, case files, solver logs, results, notes, and reports — remain on your local machine. Only the prompt context you choose to send is passed to the selected LLM endpoint, such as natural-language instructions, selected snippets, structured parameters, or screenshots added to chat. 项目产物——几何、网格、算例文件、求解日志、结果、笔记和报告——都保存在本地机器上。只有您选择发送的 prompt 上下文会传递给选定的大模型端点，例如自然语言指令、选中片段、结构化参数或加入对话的截图。
